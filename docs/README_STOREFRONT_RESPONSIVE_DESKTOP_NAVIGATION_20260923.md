# Storefront responsive desktop navigation hot patch — 2026-09-23

Extends the approved mobile-first storefront navigation to desktop/tablet without changing backend APIs or databases.

- Brand at upper left and icon-only account control at upper right.
- Delivery location below the brand and above search.
- Search uses the lens inside the search field; no separate green search button.
- Basket and WhatsApp are removed from their former top/floating positions and available in the bottom navigation.
- Bottom navigation exposes Home, Categories, Top Picks, WhatsApp and Basket on desktop and mobile.
- Existing Shop by category mega-menu, authentication, location, search, WhatsApp URL and basket logic are reused.
