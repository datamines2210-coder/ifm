# Shop by category mega-menu hot patch

Baseline: `indian-family-market-production-20260923-022023.zip`.

- Keeps **Shop by category** as highlighted navigation text with a dropdown arrow.
- Opens a downward three-column mega-menu beneath the navigation bar instead of a centered modal.
- Uses live catalog categories and products from `/api/catalog`; no screenshot sample data is hard-coded.
- Category selection updates the Browse and Products & others columns.
- Closes on repeated toggle, outside click, Escape, or product/view-all selection.
- Mobile layout adapts to two columns plus a full-width products section.
