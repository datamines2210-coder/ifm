# Storefront mobile-first navigation — 2026-09-23

Mobile storefront header is reorganized into brand/account, delivery location, then a full-width search field with the search lens inside the left edge. The visible Login / Sign up text, top Basket, and floating WhatsApp control are suppressed on mobile while retaining their underlying functions.

A fixed mobile bottom navigation provides Home, Categories, Top Picks, WhatsApp, and Basket. Categories reuses the existing Shop by category mega-menu, WhatsApp reuses `/api/public-config`, and Basket reuses the existing cart with a synchronized quantity badge. Desktop behavior is preserved.
